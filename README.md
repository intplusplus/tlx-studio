# TLX Studio

**浏览器里可训练、可推理的一体化语言模型工作站。**

整个应用就是一个 `index.html`——没有构建步骤，没有依赖，没有后端。打开页面即用。

## 特性

- **单文件**：一个约 2.7 万行的 HTML 文件承载全部 UI、状态与运行时，零依赖、零构建
- **在浏览器里训练**：预训练 / SFT / 强化学习，训练循环跑在本地
- **自研 WebGPU 算子图推理**：不走第三方推理框架，算子图直接生成并调度到 GPU
- **模型中心**：训练快照(IndexedDB)、开源权重(OPFS)、下载、导入导出、分享包，一处管理
- **公开权重一键加载**：支持直接加载公开模型权重
- **P2P 联邦训练**：多端协同训练
- **数据全程本地**：不落服务器，不上传

## 运行

推荐用本地静态服务器打开（WebGPU 与模块 Worker 在 `file://` 下可能受限）：

```bash
python -m http.server 8000
```

然后访问 <http://localhost:8000>。

也可以直接双击 `index.html` 打开，部分高级功能可能受浏览器安全策略限制。

## 浏览器要求

需要支持 **WebGPU** 的现代桌面浏览器（Chrome / Edge 等较新版本）。不支持 WebGPU 时，页面会退化到 CPU 路径，速度显著变慢。

## 说明

- 设计变量、主题系统集中在 `:root` 的 CSS 变量中，深浅色主题各一套
- 训练与推理均在浏览器本地完成，关闭页面不会保留模型状态，请及时导出
